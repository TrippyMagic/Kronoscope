# Performance Improvements

Future performance work should be measurement-led.

## Candidate Areas

- dense Timeline scene generation
- canvas draw cost under pan and zoom
- interactive target hit testing with large groups
- public JSON parse cost for larger datasets
- 3D quality profile budgets
- Timescales overview marker density

## Acceptance

- define scenario and dataset
- record baseline
- apply the smallest useful optimization
- verify no public behavior change
